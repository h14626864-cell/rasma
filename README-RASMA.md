# رسمة — منصة خريجي كليات الفنون الجميلة 🎨

منصة بورتفوليو لخريجي وطلاب كليات ومعاهد الفنون الجميلة: كل فنان بينزّل لوحاته ويبيعها، وبياخد **لينك خاص بيه من غير اسم الموقع** (`hamza.rasma.vercel.app`)، والناف بار في صفحته **باسم هو بس**.

## المميزات

### للفنان
- تسجيل: اسم، موبايل، خريج/طالب، الكلية، نبذة، صورة شخصية (اختياري — بتتنضغط تلقائيًا مع الحفاظ على الجودة)
- **اسم بورتفوليو** بيبقى لينك مستقل: `اسمك.الدومين`
- لوحة تحكم: تعديل البيانات في أي وقت + إضافة لوحات (اسم، سعر، وصف، صورة)
- زرار **واتساب** اختياري تحت شمال في صفحته، برقم بيحدده هو
- استفسارات الزوار بتوصل للوحة تحكمه + طلبات شراء بحالة (جديد → تم التواصل → تم البيع/ملغي)
- إحصائياته: مشاهدات، لوحات، مبيعات، استفسارات جديدة + نسخ لينك صفحته

### للزائر
- تصفح الفنانين واللوحات والبحث
- صفحة فنان مستقلة تمامًا (من غير هوية الموقع)
- زرار «اشتري الآن» بيفتح فورم **معبّى ببيانات اللوحة** وبيانات المشتري بتوصل للفنان

### للإدارة `/admin`
- نظرة عامة: 12 مؤشر (فنانين/خريجين/لوحات/مباعة/قيمة الكتالوج/المبيعات/مشاهدات/استفسارات/طلبات) + رسوم بيانية (نمو التسجيلات 30 يوم — اللوحات حسب الكلية — حالة طلبات الشراء) + الأكثر مشاهدة وتفاعلًا + آخر النشاطات
- إدارة الفنانين: بحث، إيقاف/تنشيط، حذف نهائي
- إدارة اللوحات: بحث وفلتر، تمييز في الرئيسية ⭐، تعليم مباعة، حذف
- إدارة طلبات الشراء: تغيير الحالات + حذف
- إدارة الاستفسارات
- الإعدادات: نصوص الصفحة الرئيسية + شريط إعلان + تغيير كلمة سر الأدمن
- **تصدير CSV** (فنانين / لوحات / طلبات)

## 1) التشغيل محليًا

```bash
npm install          # بينفّذ prisma generate تلقائيًا
cp .env.example .env # وبعدين عدّل DATABASE_URL
npx prisma db push   # إنشاء الجداول
npm run db:seed      # (اختياري) بيانات ديمو
npm run dev
```

بيانات ديمو بعد الـ seed:
- أدمن: `01003028980` / `Hamoza@12345`
- فنانين: `01000000001` (hamza) و`01000000002` (sara) و`01000000003` (omar) — كلمة السر `123456`

## 2) قاعدة البيانات على Neon (مجاني)

### ✅ الموقع منشور فعلًا على Vercel
- **اللينك: https://rasma-plum.vercel.app** (اسم `rasma` كان متاخد عالميًا فاتضافل `-plum`)
- متبقي خطوة **واحدة بس**: تركيب Neon — واختار واحدة من طريقتين:

### الطريقة (أ) — من داخل Vercel (موصى بيها)
1. افتح [vercel.com/dashboard](https://vercel.com/dashboard) → تبويب **Storage**
2. **Create Database** → اختار **Neon Postgres** → خطة **Free** → **Install**
3. هتطلب منك تسجيل دخول Neon (Google أو GitHub — دقيقة واحدة)
4. لما تخلص — نفّذ السكريبت المرفق وهو بيعمل كل حاجة (إنشاء القاعدة + الجداول + الديمو + الربط + إعادة النشر):
   ```bash
   VERCEL_TOKEN=توكنك bash scripts/setup-neon.sh
   ```

### الطريقة (ب) — من موقع Neon مباشرة
1. اعمل حساب على [neon.tech](https://neon.tech) → **New Project**
2. انسخ **Connection String** (اختار **Pooled**) — شكله:
   ```
   postgresql://user:password@ep-xxxx-pooler.REGION.aws.neon.tech/neondb?sslmode=require
   ```
3. ابعته للي عمل معاك الموقع وهو هيكمله، أو اعمله بنفسك:
   ```bash
   # محليًا: حط اللينك في .env وبعدين
   npx prisma db push && npm run db:seed
   # وعلى Vercel: Settings → Environment Variables → DATABASE_URL + DIRECT_URL → Redeploy
   ```

## 3) الحالة على Vercel (موجود فعلًا)

مشروع **`rasma`** منشور ومرتبط بالحساب، ومتغيرات البيئة متظبطة:
| المتغير | الحالة |
|---|---|
| `DATABASE_URL` | ✓ Neon Pooled (+ pgbouncer=true) |
| `DIRECT_URL` | ✓ Neon Unpooled — للـ migrate |
| `AUTH_SECRET` | ✓ متولد عشوائي |
| `ROOT_DOMAIN` | ✓ `rasma-plum.vercel.app` |
| `NEXT_PUBLIC_ROOT_DOMAIN` | ✓ نفس القيمة |

لإعادة النشر بعد أي تعديل: `vercel deploy --prod --token=توكنك`

## 4) لينكات الفنانين ⭐

**اللينك الرسمي لكل فنان صفحة جانبية ثابتة وواضحة:**

```
rasma-plum.vercel.app/artist/hamza
```

- اللينك ده هو اللي بيتعرض في التسجيل ولوحة تحكم الفنان — **شغال دايمًا على أي دومين**
- اللينك بيتولد تلقائيًا من الدومين اللي الموقع شغال عليه (`window.location.origin`) — يعني لو غيرت الدومين، كل اللينكات تتحدث لوحدها

**اختياري (بونص) — بدومين مخصص (مثال: `rasma.com`) تقدر تفعّل الـ subdomains كمان:**
1. اشترِ الدومين وأضفه في Vercel → Project → **Settings → Domains**
2. عند الـ DNS بتاع الدومين، ضيف سجلين:
   - `A Record` باسم `@` يشير لـ `76.76.21.21`
   - `CNAME Record` باسم `*` (wildcard) يشير لـ `cname.vercel-dns.com`
3. حدّث `ROOT_DOMAIN` و`NEXT_PUBLIC_ROOT_DOMAIN` في Vercel ليكونوا `rasma.com` واعمل **Redeploy**
4. بعد ما الـ DNS ينتشر — **أي فنان هياخد أوتوماتيك `hamza.rasma.com`** 🎉 وصفحته هتبقى باسمه فقط من غير أي ذكر للموقع

الانتقال بين الوضعين بيحصل تلقائيًا — نفس الكود، مجرد متغير البيئة.

## 5) بيانات الدخول

| الجهة | اللينك | الدخول |
|---|---|---|
| الفنان | `/register` | تسجيل جديد (مجاني) |

## 6) بنية المشروع

```
prisma/schema.prisma      → قاعدة البيانات (PostgreSQL/Neon)
src/middleware.ts         → تحويل subdomain الفنان لبورتفوليو
src/app/(site)/           → صفحات الموقع (الرئيسية/الفنانين/اللوحات/التسجيل/الداشبورد/الأدمن/الشراء)
src/app/artist/[slug]/    → بورتفوليو الفنان (صفحة مستقلة بهويته)
src/app/api/              → REST API (auth/artist/public/admin)
src/components/site/      → مكونات الواجهة
src/lib/                  → auth/compress/db/slug/types
public/demo/              → صور ديمو (تقدر تمسحها)
scripts/seed.ts           → بيانات ديمو (اختياري)
```
